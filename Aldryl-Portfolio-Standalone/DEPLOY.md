# Publish this Independent Portfolio Copy

## Vercel

1. Create a **new** project and import a **new repository** containing these files, or upload the folder using your preferred deployment tool.
2. Set the framework preset to **Other** (static HTML/CSS/JS).
3. Leave the build command empty; set the output directory to the repository root (`.`), if prompted.
4. Deploy and open the URL assigned to your **new** project.

## GitHub Pages — New Repository

1. Create a new, empty repository under the GitHub account you wish to use.
2. Upload **these site files** to its root, including `index.html`.
3. Open **Settings → Pages → Build and deployment** in that new repository.
4. Select **Deploy from a branch**, branch **main**, and folder **/(root)**, then save.
5. Open the new repository's Pages URL shown in Settings → Pages after publication.

## Other static hosts / Tanix

Use `index.html` as the entry point and keep `styles.css`, `portfolio-refresh.css`, `site.js`, and `assets/` beside it. No Node, npm, or framework build is required.

## Verify after publishing

Check the hero, section navigation, mobile menu, light/dark toggle, portfolio cards, and any PDFs you have added. Confirm that the live URL belongs to your new hosting account.

No git remote, automated GitHub Actions workflow, legacy repository links, or old hosting URL is included in this package.
